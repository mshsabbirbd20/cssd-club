# CSSD Club Website

Official website for the **Career & Soft Skills Development Club**, Govt. Mohammadpur Model School & College.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion

## Setup

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
cd web
npm run build
npm start
```

## Content

Edit club copy, team, FAQs, and links in `src/lib/content.ts`.

- Logo: `public/logo.png`
- Member photos: `public/members/`

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/about` | About & committee |
| `/career` | Career opportunities |
| `/join` | Membership & FAQ |
| `/contact` | Contact |
